# Orange vs Grapefruit Classifier

## Overview

This project explores machine learning classification for distinguishing
between oranges and grapefruits.

## Contents

-   `citrus_ml_training.ipynb` --- Jupyter Notebook containing the
    machine learning workflow.
-   `plots_data.pdf` --- supporting plots and data visualizations.

## Tools

-   Python
-   Jupyter Notebook
-   Machine learning
-   Data visualization

## Project Focus

The project demonstrates a classification workflow, including model
training and visual analysis of the data.

## Purpose

The goal is to explore how machine learning can be used to classify
citrus fruit based on available data.

## How to Explore

Open `citrus_ml_training.ipynb` in Jupyter Notebook or another
compatible environment to review the analysis and training workflow.
